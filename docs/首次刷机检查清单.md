# 首次刷 6.x 固件时的观察清单

刷完 `reset` 之后，串口里按这个顺序看，基本能一眼定位问题。

## 1. 正常应该看到

```
U-Boot 2016.01 ...            <- 引导起来了
Starting kernel ...           <- 换内核成功
[    0.000000] Booting Linux on physical CPU 0x0
[    0.000000] Linux version 6.18.x ...   <- 新内核
[    0.000000] Memory: ... available        <- 内存大小是否接近 992MB
[    0.xxx] mmc0: SDHCI controller ...      <- eMMC 认到了
[    0.xxx] mmc0: new DDR MMC card at address 0001
[    0.xxx] VFS: Mounted root (squashfs filesystem)
[    x.xxx] procd: - init -
```

## 2. 关键检查点（照抄 `dmesg` 里的关键字）

| 关键字 | 期望 | 说明 |
|---|---|---|
| `qca8k` | 出现 `qca8k-8xxx ... switch` 之类的行 | **网口生死线**。没有就是交换机没绑上 |
| `dsa` / `lan1` | `ls /sys/class/net` 里有 `lan1..lan4`、`wan` | DSA 端口建出来了 |
| `mmc0` | 有 `new DDR MMC card` | eMMC 正常 |
| `ath10k` | `ath10k_pci ... firmware` | 无线；没有也不影响先用的网口 |
| `Memory:` | 约 99x MB | 和 DTS 里 `0x3e000000` 对得上 |

## 3. 常见失败 → 对应处理

| 现象 | 原因 | 处理 |
|---|---|---|
| 卡在 `Starting kernel ...` 不动 | DTB 与内核不匹配 / 内存大小不对 | 换 `-alt` 那版；仍不行则改 `memory@0` |
| `Kernel panic - not syncing: VFS: Unable to mount root fs` | rootfs 没写进去，或 `root=` 指向错分区 | 确认 `flash.scr` 里 `rootfs` 写到 LBA 21526；确认 DTS `append-rootblock` |
| 起来了，但 `ip link` 只有 `lo` | 交换机驱动没绑 | 刷 `-alt`（地址 0x10）；还不行就是芯片 ID 不匹配，要改 `compatible` |
| 有 `lan1..wan`，插网线灯不亮/不通 | DSA 端口映射与实物不符 | 把 `/sys/class/net` 和面板丝印对一下，改 DTS 的 `port@N` label |
| 无线没出来 | 缺 `0:ART` 校准 | 先不管；后续补 `11-ath10k-caldata` 的 norton 分支 |

## 4. 取证方式（方便我下一轮直接改）

刷完后在串口里：

```sh
dmesg | grep -iE 'qca8k|dsa|mmc|ath10k|error|fail' 
ls /sys/class/net
cat /proc/cmdline
```

把这三条的输出发我即可。

## 5. 回滚（任何情况下都能救）

只要能进 U-Boot：

```
setenv serverip 192.168.1.10
setenv ipaddr 192.168.1.2
tftpboot ntbsubootemmc-ipq806x-single.img
imgaddr=0x44000000 && source $imgaddr:script
```

或者刷回 QSDK 那份 `norton_core-518-ipq806x-emmc-qsdk-1.img`（不动 ART）。
